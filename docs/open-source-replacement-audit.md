# 开源组件替代审计（已退役）

2026-08-25–26 的审计和实现证据保存在 Git 历史中。该轮关于多宿主、旧存储后端、兼容窗口和产物体积的约束已被新的部署方向替代，不再用作当前实现或验收指导。

当前工作以 [Self-hosted 架构重构方案](./self-hosted-architecture-refactor.md)、[llmdoc 架构](../llmdoc/architecture.mdx) 与代码为准。不要根据旧审计中的源码行数、测试数量、包版本或候选库结论推断本轮完成状态。

仍适用的工程原则：

- 复用成熟库承担协议、数据库和对象存储实现，保留 Tool Bridge 的授权与执行语义。
- 用真实 HTTP、数据库并发、流式对象操作和故障恢复验证替换，不以净删行数代替正确性。
- SDK 中立子入口保持独立，服务端依赖不得泄漏到浏览器和设备客户端。
- 密钥不进入节点公开配置，出站请求继续执行受控网络策略。
- 设备 generation、Mailbox 结果确定性和本地 journal 属于执行安全边界。
- 发布前通过全仓验证、构建和确切 tarball 验证；真实外部资源验证每轮最多一次并留证据。
