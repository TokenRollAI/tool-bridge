The service starts a protected setup page before PostgreSQL is configured.
Forward port 8787 to the app pod and open http://127.0.0.1:8787/ui/setup.
Get a short-lived pairing credential by running in that pod:
  node /app/dist/admin.js pair --directory /data/bootstrap
Configure PostgreSQL, S3 and (before using multiple replicas) Redis in Dashboard.
Only bootstrap identity and encryption roots use this PVC; object bytes reside in S3.
